Subagent 的核心
    SUBAGENT

    一个主 Agent 对最终结果负责

    像项目负责人带专业成员：主 Agent 拆解、委派、收回摘要，再统一决策。子 Agent 通常拥有独立上下文，避免所有细节挤进主上下文。

    MULTI-AGENT

    多个 Agent 围绕共享目标协同

    像一个跨职能小组：角色之间可以交换中间结果、提出异议和交叉校验。协调成本更高，但适合复杂、开放且需要多视角判断的任务。
